## 🚀 Stack Overview

This modern web application leverages the latest React and Next.js features to provide a fast, optimized development experience with cutting-edge tooling.

### Core Technologies

- **Next.js 16** - React framework with App Router and server components
- **React 19** - Latest React with experimental compiler support
- **Dart Sass** - Modern SCSS compiler with advanced features
- **ESLint** - Code quality and consistency enforcement
- **Babel React Compiler** - Experimental optimization plugin

## 📋 System Requirements

### Node.js Version
- **Required**: Node.js ≥ 18.18.0
- **Recommended**: Node.js 20.x LTS or 22.x
- **Why**: Next.js 16 compatibility, modern JavaScript features, and optimal performance

### Package Manager
- **npm** ≥ 9.0.0 (comes with Node.js 18+)
- **Alternatives**: Yarn, pnpm, or Bun

### Check Your Versions

```bash
node --version  # Should be >= 18.18.0
npm --version   # Should be >= 9.0.0
```

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
